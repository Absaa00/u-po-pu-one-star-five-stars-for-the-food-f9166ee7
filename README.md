# One Star, Five Stars for the Food

[![make.fun](https://make.fun/badge.svg)](https://make.fun/competitions/u-po-pu-one-star-five-stars-for-the-food-f9166ee7)

Entry for the [make.fun bounty "One Star, Five Stars for the Food"](https://make.fun/competitions/u-po-pu-one-star-five-stars-for-the-food-f9166ee7): one sentence, at most 200 characters, in the voice of an alien tourist giving planet Earth a one-star review while still slipping in a real compliment about the food.

## The entry

> One star: the locals queue for everything, the air tastes pre-owned, and gravity never lets go, but the ramen alone justifies the nine-light-year trip.

151 characters, one sentence, deterministic.

## Run

```sh
python3 main.py   # writes the sentence to /output/entry.txt
```

No network, no randomness, no dependencies beyond Python 3.13's standard library.
